# ai-workflow-projects
AI workflow and prompt engineering projects

## Projects
| Project | What it does |
|---|---|
| [requirement-to-testplan-agent](requirement-to-testplan-agent/) | Turns written requirements into test plans, with versioned prompts, an evaluation set and human review for uncertain items |
| [data-quality-reconciliation-agent](data-quality-reconciliation-agent/) | Compares a source dataset to a reporting dataset, profiles both, flags mismatches and writes a review queue or a match summary. Config-driven and reusable |

All projects use synthetic data only.
